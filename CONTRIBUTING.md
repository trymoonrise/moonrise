# Contributing to Moonrise Studio

Thanks for your interest in Moonrise.

Moonrise Studio is the hosted product at [trymoonrise.com](https://trymoonrise.com). This repository explains that product. It is not a download, and it is not meant to be installed or hosted by anyone else.

Useful notes are product feedback, bug reports, and clear ideas that make finding a business, building a site, sharing a preview, or getting paid easier.

## Ways to help

- Report bugs you hit while using Studio
- Suggest features that make finding, building, presenting, or getting paid easier
- Share feedback on clarity, wording, and user flow
- Point out broken links, confusing pages, or accessibility issues

## Before you open an issue

1. Check whether the issue already exists
2. Include what you were trying to do
3. Include what happened instead
4. Add screenshots when they help

## Feature requests

Good feature requests usually answer:

- Who is this for?
- What problem does it solve?
- What would "done" look like?

## Product changes

Moonrise is an active product. Not every suggestion can be accepted. Thoughtful feedback is welcome.

Describe what a person was trying to do in Studio and what would be better. Do not send setup steps, credentials, or a request to republish the product.

## Conduct

Be respectful. No harassment, spam, or bad-faith reports. See [CODE_OF_CONDUCT.md](.github/CODE_OF_CONDUCT.md).

For security reports, use [SECURITY.md](SECURITY.md) — never post secrets or exploit details in public issues.
