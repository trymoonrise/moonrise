Install Moonrise

Moonrise Studio is a website and an installable web app. There is no separate App Store or Play Store listing.

How to install

  1. Open Download

    Go to trymoonrise.com/download on the phone or computer you want to use.

  2. Use the browser install prompt

    On supported browsers, choose Add to Home Screen or Install. The app name is Moonrise Studio. The short name is Moonrise.

  3. Sign in

    Open the installed app and sign in when you are ready to build.

Why install

Home-screen access keeps Studio one tap away. Push alerts can help with client activity when you enable them in Settings.
